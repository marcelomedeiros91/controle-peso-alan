Sincronização Automática em Nuvem Ativa

Seus registros e metas são sincronizados automaticamente em tempo real. Além disso, para publicar no GitHub Pages e alimentar pelo PC e Celular usando sua própria Planilha Google gratuita, você pode conectar uma URL do Google Apps Script abaixo:

Como conectar ao Google Planilhas (100% gratuito no GitHub Pages):

  1. Crie uma Planilha Google em branco e clique em Extensões > Apps Script.
  2. Cole o código abaixo, clique em Implantar > Nova implantação > App da Web (Acesso: Qualquer pessoa).
  3. Copie a URL gerada e cole no campo acima (no PC e no Celular).
function doGet() {
  var prop = PropertiesService.getScriptProperties().getProperty('ALAN_DATA');
  return ContentService.createTextOutput(prop || '{}').setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  PropertiesService.getScriptProperties().setProperty('ALAN_DATA', e.postData.contents);
  return ContentService.createTextOutput('{"ok":true}').setMimeType(ContentService.MimeType.JSON);
}
