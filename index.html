Sincronização (PC + Celular) & GitHub Pages

Salve seus dados localmente, em nuvem ou em Planilha Google

Passo a passo para ter nuvem gratuita no GitHub Pages:

  1. Acesse sheets.new e clique em Extensões > Apps Script.
  2. Apague tudo, cole o código abaixo e clique em Implantar > Nova implantação > App da Web (Quem pode acessar: Qualquer pessoa).
  3. Copie a URL gerada e cole acima no computador e no celular.
function doGet() {
  var prop = PropertiesService.getScriptProperties().getProperty('ALAN_DATA_V2');
  return ContentService.createTextOutput(prop || '{}').setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  PropertiesService.getScriptProperties().setProperty('ALAN_DATA_V2', e.postData.contents);
  return ContentService.createTextOutput('{"ok":true}').setMimeType(ContentService.MimeType.JSON);
}
